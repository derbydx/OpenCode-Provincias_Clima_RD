# OpenCode - Provincias Clima RD

Dashboard del clima actual para las 32 provincias de Republica Dominicana y el Distrito Nacional. Los datos meteorologicos se obtienen en tiempo real desde la API de Open-Meteo.

## Caracteristicas

- Clima actual de todas las provincias dominicanas
- Agrupacion automatica por tipo de clima (despejado, nublado, lluvia, tormentas, etc.)
- Filtros combinados: por grupo climatico, velocidad del viento, y orden (nombre o temperatura)
- Busqueda en vivo por nombre de provincia o capital
- Diseno responsive con colores de la bandera dominicana
- Sin servidor, sin API key, sin dependencias

## Tecnologias

- HTML, CSS, JavaScript vanilla
- [Open-Meteo API](https://open-meteo.com/) para datos meteorologicos
- Google Fonts (Playfair Display + Source Serif 4)

## Uso

Abrir `index.html` en cualquier navegador moderno. No requiere instalacion ni servidor.

## Estructura

```
index.html        Estructura HTML
styles.css        Estilos visuales
app.js            Logica de datos, API y filtros
```
